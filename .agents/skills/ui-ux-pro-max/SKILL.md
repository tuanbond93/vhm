# UI UX Pro Max — Operations Intelligence Design System Guidelines

## Core Principles
1. **Trust > AI Hype**: Professional, structured B2B presentation. Avoid neon gradients, glowing lines, and generic AI stock graphics.
2. **Typography & Diacritics First**: Optimized for Vietnamese diacritics using `Be Vietnam Pro` for headings, `Inter` for body text, and `IBM Plex Mono` sparingly for data/KPI badges.
3. **Operations Control Tower Theme**: Light paper-neutral background (`#F8FAFC`), deep operational navy (`#0F172A`), data blue (`#2563EB`), and functional status badges (Healthy `#166534`, Warning `#B45309`, Alert `#991B1B`).
4. **Mobile Ergonomics**: One-handed touch targets (≥ 44px), thumb-friendly header navigation, and unobtrusive sticky action bar.
